# AGENTS.md

## What this is

Elaina (魔女之旅) fan page — React SPA with routing, deployed to GitHub Pages. Homepage introduces Elaina first, then the organization.

## Stack

- React 19, Vite 8, TypeScript ~7.0, Tailwind CSS 4
- React Router for page routing (`/`, `/about`, `/projects`, `*`)
- i18next with `en` (default) + `zh-CN` locales
- `next-themes` for light/dark mode
- `animejs` for animations, `lucide-react` for icons

## Package manager

CI uses **bun**. The lockfile is `bun.lock`. README mentions npm — that's outdated, use bun.

```
bun install
bun run dev
bun run build
```

## Path alias

`@/` resolves to `src/`. Use it: `import Foo from "@/components/foo"`.

## Commands

| Command | What it does |
|---------|-------------|
| `bun run dev` | Vite dev server |
| `bun run build` | `tsc -b && vite build` — type-checks then builds to `dist/` |
| `bun run lint` | ESLint on `**/*.{ts,tsx}` |
| `bun run prettier` | Prettier on `src/` with organize-imports + tailwindcss plugins |

## TypeScript strictness

`tsconfig.app.json` has strict mode with:
- `noUnusedLocals: true`
- `noUnusedParameters: true`
- `verbatimModuleSyntax: true` — use `import type` for type-only imports

Build will fail on unused variables and parameters.

## Formatting

- `.prettierrc` at root
- `printWidth: 100`, `singleQuote: false`, `semi: true`, `trailingComma: "es5"`
- **Exception**: HTML/CSS/SCSS/MD files use `tabWidth: 4` (rest uses 2)
- Prettier plugins: `prettier-plugin-organize-imports`, `prettier-plugin-tailwindcss`

## Architecture

### Routes

| Path | Page | Description |
|------|------|-------------|
| `/` | HomePage | Hero (Elaina intro) → AboutOrg → Services → Projects → CTA |
| `/about` | AboutPage | Organization story, mission, vision + Team |
| `/projects` | ProjectsPage | Full project listing |
| `*` | NotFoundPage | 404 page |

### Component structure

- `src/components/` — shared components (header, footer, hero, about-org, services, projects, team, cta)
- `src/pages/` — page wrappers that compose components

### i18n

- `src/i18n/index.ts` — initializes i18next with `en` as default/fallback
- `src/i18n/locales/en.json`, `zh-cn.json` — translation files
- Use `useTranslation()` hook, keys like `hero.title`, `aboutOrg.badge`

## Deployment

GitHub Actions deploys `dist/` to GitHub Pages on push to `main`. Uses Bun for install and build.

## Gotchas

- `stats.html` is generated by `rollup-plugin-visualizer` and gitignored — don't commit it
- `dist/` is the build output and gitignored
- `public/404.html` is a standalone static page (not a React component) — it handles client-side routing for GitHub Pages
- The deploy workflow comment says "VitePress" but the actual build is Vite — ignore the comment
